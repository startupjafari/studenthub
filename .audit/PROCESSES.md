```

- Бизнес-цель:
- Роли:
- Вход (UI-маршрут / эндпоинт / cron / очередь / вебхук):
- Завершение:
- Шаги и файлы:
- Данные на входе / выходе:
- Внешние зависимости:
- Тесты: unit (spec) / e2e api / web unit / web e2e / нет
```
