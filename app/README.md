# StudentHub — Telegram Mini App

Каркас мини-аппа. Отдельное приложение: свой `package.json`, свои зависимости, **вне**
pnpm-воркспейса монорепо (`pnpm-workspace.yaml` покрывает только `apps/*` и `packages/*`),
поэтому `pnpm install` в корне его не трогает и `pnpm dev` не поднимает.

## Запуск

```bash
cd app
pnpm install
pnpm dev        # http://localhost:5175
```

В обычном браузере приложение работает: Telegram не подключён — берётся запасная светлая
палитра, нативные кнопки и хаптика молчат, на экране «Профиль» про это написано.

Чтобы открыть внутри Telegram, нужен https-адрес:

```bash
cloudflared tunnel --url http://localhost:5175   # или ngrok http 5175
```

Дальше в `@BotFather`: `/newapp` → выбрать бота → указать полученный https-URL. Открывается
по прямой ссылке вида `t.me/<bot>/<app>` или кнопкой `web_app` в меню бота.

## Сборка

```bash
pnpm build      # tsc --noEmit + vite build → dist/
```

`base: './'` в [vite.config.ts](vite.config.ts) — статика раздаётся с любого пути, не
обязательно из корня домена.

## Что внутри

| Файл                                                         | Зачем                                                                                                 |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| [src/telegram/webapp.ts](src/telegram/webapp.ts)             | Единственная точка доступа к `window.Telegram.WebApp`, перенос темы клиента в CSS-переменные, хаптика |
| [src/telegram/types.ts](src/telegram/types.ts)               | Типы ровно на используемую часть API — вместо пакета-обёртки                                          |
| [src/telegram/use-telegram.ts](src/telegram/use-telegram.ts) | Хуки над `BackButton` и `MainButton`                                                                  |
| [src/app.tsx](src/app.tsx)                                   | Навигация состоянием: три вкладки + один экран вглубь                                                 |
| [src/screens/](src/screens/)                                 | Расписание, детали пары, задания, профиль                                                             |
| [src/mocks/data.ts](src/mocks/data.ts)                       | Демо-данные в формах будущих ответов API                                                              |

Решения, которые стоит знать до правок:

- **SDK подключается тегом из `index.html`, а не пакетом.** Библиотека обязана быть готова
  до первого рендера, и Telegram обновляет её вместе с клиентом; локальная копия устаревает.
- **Всё работает вне Telegram.** `webApp()` возвращает `null`, обёртки молчат. Иначе отладка
  превращается в «проверяй только с телефона».
- **Цвета — только через `--tg-theme-*`.** Клиент меняет тему на лету; своя палитра сразу
  разъедется с окружением.
- **`onClick` у кнопок Telegram добавляет обработчик, а не заменяет.** Снятие обязательно,
  иначе после нескольких переходов один тап вызовет несколько колбэков — этим занимаются
  хуки в `use-telegram.ts`.

## Чего здесь нет

Обращения к API StudentHub. Мини-апп идентифицирует пользователя строкой `initData`, и
доверять ей можно только после проверки HMAC-подписи **на бэкенде**: `initDataUnsafe` в
названии — не преувеличение, клиент отдаёт эти поля без проверки. Такой эндпоинт — публичный
вход в платформу, его добавление согласуется отдельно (`AGENTS.md`, стоп-точки 3 и 4).
До тех пор экраны живут на моках из `src/mocks/data.ts`.
