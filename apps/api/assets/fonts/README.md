# Шрифты для PDF

`InterVariable.ttf` — Inter 4.0 (rsms/inter), лицензия SIL Open Font License 1.1.
OFL прямо разрешает встраивание шрифта в документы, поэтому файл лежит в репозитории
и попадает в сборку.

Зачем файл вообще нужен: четырнадцать стандартных шрифтов PDF не содержат кириллицы,
и резюме на русском без встроенного шрифта вышло бы пустым. Посубсетные пакеты
(`@fontsource/*`) не подходят — они разделяют латиницу и кириллицу по разным файлам,
а `Font.register` в react-pdf связывает семейство с одним файлом на начертание.
