# Шрифты для PDF

`InterVariable.ttf` — Inter 4.0 (rsms/inter), лицензия SIL Open Font License 1.1.
OFL прямо разрешает встраивание шрифта в документы, поэтому файл лежит в репозитории
и попадает в сборку.

Зачем файл вообще нужен: четырнадцать стандартных шрифтов PDF не содержат кириллицы,
и документ на русском без встроенного шрифта вышел бы пустым. Посубсетные пакеты
(`@fontsource/*`) не подходят — они разделяют латиницу и кириллицу по разным файлам,
а `Font.register` в react-pdf связывает семейство с одним файлом на начертание.

Шрифт один на все PDF платформы — резюме (`src/modules/career/resume-pdf.ts`) и справка
об обучении (`src/modules/application-services/study-certificate-pdf.ts`). Регистрирует его
`src/common/export/pdf-font.ts`; файл не найден — генерация падает с ошибкой, а не выдаёт
пустой документ. Казахские буквы (Ә Ғ Қ Ң Ө Ұ Ү Һ І) в нём есть, так что kk-документы
тоже годятся.
