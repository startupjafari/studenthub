# Агент камер StudentHub

Программа, которую вуз запускает у себя, в сети с камерами. Она связывает камеры с
платформой, ничего не открывая наружу:

- агент **сам** ходит к платформе по HTTPS, входящих портов в сети вуза не нужно;
- адреса камер и зашифрованные пароли получает с платформы, расшифровывает их своим ключом
  и держит только в памяти;
- раз в минуту проверяет каждую камеру и сообщает её состояние: в сети, нет связи, неверный
  пароль;
- видео отдаёт только пока его кто-то смотрит (с этапа «ретранслятор»).

Устройство и данные — `docs/PROJECT.md` §3.10.

## Установка в вузе

Нужен любой сервер или мини-ПК с Docker, который видит камеры (или регистратор) и выходит
в интернет на 443 порт.

1. Администратор вуза в StudentHub: «Камеры» → «Добавить агента» → скопировать токен.
   Токен показывается один раз.
2. На сервере:

   ```bash
   docker run -d --name studenthub-agent --restart unless-stopped \
     -e STUDENTHUB_API_URL=https://<адрес API>/api/v1 \
     -e STUDENTHUB_AGENT_TOKEN=<токен> \
     -v studenthub-agent:/var/lib/studenthub-agent \
     <образ агента>
   ```

3. Через несколько секунд агент в разделе «Камеры» станет «На связи». После этого можно
   добавлять камеры с паролями.

**Том `studenthub-agent` обязателен.** В нём закрытый ключ агента, которым расшифровываются
пароли камер. Пересоздали контейнер без тома — ключ потерян, платформа ответит, что знает
другой ключ. Выход: «Перевыпустить токен», запустить агента с новым токеном и ввести
пароли камер заново.

## Настройки

| Переменная                    | Обязательна | Что это                                                  |
| ----------------------------- | ----------- | -------------------------------------------------------- |
| `STUDENTHUB_API_URL`          | да          | адрес API с `/api/v1`, только `https://`                 |
| `STUDENTHUB_AGENT_TOKEN`      | да          | токен из раздела «Камеры» (`shca_…`)                     |
| `STUDENTHUB_STATE_DIR`        | нет         | каталог ключа, по умолчанию `/var/lib/studenthub-agent`  |
| `STUDENTHUB_PROBE_INTERVAL_S` | нет         | как часто проверять камеры, по умолчанию 60, минимум 10  |
| `STUDENTHUB_ALLOW_INSECURE`   | нет         | `1` разрешает `http://` — только для стенда разработчика |

## Что смотреть, если не работает

`docker logs studenthub-agent` — журнал строками JSON. Пароли и токен туда не попадают.

| Сообщение                                  | Что делать                                                            |
| ------------------------------------------ | --------------------------------------------------------------------- |
| «Токен агента не принят платформой»        | токен отозван или перевыпущен: взять новый в «Камерах»                |
| «Платформа знает другой ключ этого агента» | потерян том с ключом: перевыпустить токен, ввести пароли камер заново |
| «Пароль камеры не расшифровать»            | пароль задавали для прежнего ключа: задать его заново в «Камерах»     |
| «Платформа недоступна, повтор»             | нет выхода в интернет или платформа на обновлении: агент повторит сам |

## Разработка

```bash
pnpm --filter camera-agent test      # сборка + node --test
docker build -f apps/camera-agent/Dockerfile -t studenthub-camera-agent:dev .
```

Проверка на эмуляторе камер — `docker/camera-sim/README.md`, раздел «Агент».

Зависимостей во время работы нет: только встроенные модули Node (`fetch`, `crypto`,
`child_process`) и `ffprobe` из образа. Формат конверта с паролем — зеркало
`apps/api/src/common/crypto/sealed-box.ts`; совпадение проверяет тест на векторе, выпущенном
кодом платформы.
