# Chat Lab — личный чат по образцу Telegram iOS

Отдельное iOS-приложение (iOS 26+, Swift, UIKit + Core Animation) для отработки поведения
чата Telegram: прокрутки, жестов, анимаций, клавиатуры, меню и медиа. Один личный чат с
вымышленной собеседницей (Алина Соколова), всё локально: без сервера, API и авторизации.
Приложение открывается сразу в переписке; под ней — список чатов, чтобы работали «назад» и
свайп назад.

Разбор исходников Telegram-iOS, из которого взяты механизмы и числа, —
[`TELEGRAM_CHAT_ANALYSIS.md`](TELEGRAM_CHAT_ANALYSIS.md). Код Telegram (GPLv2) не копировался.

Каталог не входит в pnpm/turbo: у него нет `package.json`.

## Быстрый старт

| Где       | Команда                              | Что делает                                                                                        |
| --------- | ------------------------------------ | ------------------------------------------------------------------------------------------------- |
| macOS     | `./scripts/setup.sh`                 | проверяет Xcode 26+ и XcodeGen, находит вашу команду разработчика, генерирует `ChatLab.xcodeproj` |
| macOS     | `./scripts/build.sh`                 | Debug под симулятор (`--device` — под iPhone, `--release`)                                        |
| macOS     | `./scripts/test.sh`                  | unit + UI на симуляторе (`unit`, `ui`, `all` — с замерами)                                        |
| macOS     | `./scripts/run-performance-tests.sh` | замеры в Release, на iPhone, если подключён                                                       |
| macOS     | `./scripts/install-iphone.sh`        | сборка, установка и запуск на подключённом iPhone                                                 |
| Linux/WSL | `./scripts/build.sh`                 | проверка компиляции под iOS (Darwin SDK из xtool)                                                 |
| Linux/WSL | `./scripts/build.sh --tests`         | проверка компиляции unit-, UI- и perf-тестов (без запуска)                                        |
| Linux/WSL | `./scripts/install-iphone.sh`        | `xtool dev run`: сборка, подпись личным Apple ID, установка                                       |

Проект Xcode — `apps/ios-chat-lab/ChatLab.xcodeproj`. Он генерируется из `project.yml` и
в git не хранится. Цели: `ChatLab`, `ChatLabTests`, `ChatLabUITests`, `ChatLabPerfTests`;
схемы `ChatLab` (Debug, unit + UI) и `ChatLabPerf` (Release, замеры).

### Установка на iPhone

**macOS + Xcode 26.**

1. Xcode → Settings → Accounts: войдите своим Apple ID (бесплатного хватает).
2. `./scripts/setup.sh` читает Team ID из `DEVELOPMENT_TEAM` или из сертификата
   «Apple Development» в связке ключей и пишет его в `Config/Signing.local.xcconfig` (файл не в
   git). Чужие сертификаты и настройки подписи скрипт только читает.
3. На iPhone: подключить кабелем, «Доверять», включить «Настройки → Конфиденциальность →
   Режим разработчика».
4. `./scripts/install-iphone.sh` (для честной плавности — `--release`).

**Linux/WSL (как `apps/ios`).** Нужен `xtool` (`xtool setup`, вход Apple ID). В WSL телефон
виден через usbipd или через службу Apple в Windows (порт 27015 — как в
`apps/ios/scripts/device.sh`). Затем `./scripts/install-iphone.sh`. Bundle ID этой сборки —
`kz.studenthub.chatlab.dev`, чтобы не конфликтовать с Xcode-сборкой.

## Что реализовано

**Лента** (`Sources/Chat`)

- Перевёрнутый список, как `ChatHistoryListNode`: самое новое — строка 0, низ ленты не требует
  пересчёта смещения. Раскладка пузырей считается заранее через Core Text (`MessageLayoutEngine`,
  `TextLayout`), ячейки только расставляют виды.
- Точечные обновления по стабильным `RowID`: вставка снизу «вырастает» на 1,6 высоты,
  удаление гаснет и сжимается до 0,1, соседи съезжают за 0,4 с. Изменённые строки
  перенастраиваются на месте.
- Если пользователь не внизу, позиция держится за якорь (первую видимую строку): входящие и
  правки не двигают читаемое. Появляется кнопка «вниз» со счётчиком новых.
- Серии пузырей: хвост только у последнего, малые углы между соседями, порог 10 минут.
  Даты-плашки, плавающая дата при прокрутке, служебные сообщения.
- Содержимое: текст со ссылками (нажатие открывает Safari внутри приложения), крупные эмодзи
  без пузыря, фото, видео, GIF (играют в ленте), альбомы-мозаика, файлы (Quick Look),
  голосовые (волна, проигрывание, скорость, автопереход к следующему), кружки (тихо по кругу,
  по нажатию со звуком и кольцом), ответы (нажатие — переход с подсветкой), пересланные,
  «изменено», реакции, статусы: часы → ✓ → ✓✓ → ✓✓ цветом прочтения, ошибка с повтором.
- Обои: четырёхцветный градиент с узором, точки сдвигаются при отправке, как у Telegram;
  6 вариантов, светлая и тёмная тема.

**Жесты и анимации** (числа — из `TELEGRAM_CHAT_ANALYSIS.md`)

- Свайп-ответ: порог 60/45 pt, дальше сопротивление `s + (1 − 1/((x−s)·0.4/100+1))·100`,
  не больше 180 pt; сильный тактильный отклик на пороге, «подпрыгивание» значка.
- Долгое нажатие: через 0,12 с пузырь вдавливается за 0,2 с, затем меню.
- Отправка: пузырь вылетает из поля ввода, вертикаль и горизонталь — разными кривыми Telegram.
- Переход к сообщению: display link по кривой Telegram, издалека — «прыжок + короткая
  прокрутка», подсветка 0,7 с + 0,3 с.
- Клавиатура: `keyboardLayoutGuide`, лента едет вместе с панелью, интерактивное закрытие свайпом.
- Свайп назад с любого места (iOS 26), профиль — системный переход с полётом аватара.

**Меню сообщения** — снимок пузыря над размытым фоном, панель реакций (7 + раскрытие),
действия Ответить, Копировать, Переслать, Изменить, Закрепить, Выбрать, Удалить. Отступы
и пружина — как у Telegram; пункты можно выбирать, не отпуская пальца.

**Панель ввода** — растущее поле, эмодзи-клавиатура (около 1000 символов, недавние),
вложения: галерея PHPicker, камера, файлы, тестовые фото с предпросмотром и подписью.
Голосовые: удержание 0,19 с, отмена свайпом влево, закрепление вверх, предпросмотр перед
отправкой. Кружки: фронтальная камера; где камеры нет — тестовый кружок. Ответ и
редактирование с отменой, черновик сохраняется.

**Просмотрщик медиа** — полёт из плитки, листание всех медиа чата, масштаб до 4× и
двойное касание, видео с панелью, закрытие жестом (1000 pt/с или ¼ высоты), «Поделиться»,
«Сохранить в Фото», «Перейти к сообщению», «Удалить».

**Профиль** — аватар, имя, статус, телефон, username, «о себе», без звука, блокировка,
поиск, общие медиа, файлы, ссылки, голосовые.

**Ещё** — поиск по чату с навигацией «N из M» и подсветкой, закрепы (панель с переключением,
служебное сообщение), множественный выбор и массовое удаление/пересылка, очистка истории с
подтверждением, пересылка в демо-чаты, локальные уведомления, «печатает…», автоответы.

**Данные** — `MockChatService`: 340 сообщений за 7 недель из 108 диалогов на русском, все
виды сообщений. Медиа генерируются на устройстве при первом запуске (`MediaFactory`): фото,
видео H.264, кружки со звуком, GIF, голос AAC с той же формой волны, PDF/TXT/CSV.
Состояние — JSON в Application Support, запись в фоне.

**Debug Menu** («Ещё → Debug Menu» или долгое нажатие тремя пальцами): получить 1 и 10
сообщений, печать собеседника, входящие фото, голосовое и кружок, отправить фото и голосовое,
медленная сеть, ошибка следующей отправки, автоответы, прочтение, входящее через 5 с (для
уведомления), монитор кадров, сброс данных.

## Тесты

- **Unit** (`Tests/ChatLabTests`): строки ленты и серии, раскладка пузырей, мозаика, ссылки,
  хранилище (правка, удаление, реакции, закреп, пересылка, поиск, очистка, JSON), исходная
  история (≥ 300, детерминированность, все виды), формула свайпа, кривая Безье, форма волны.
- **UI** (`Tests/ChatLabUITests`), пункты 1–16 задания и ещё 2 сценария. Каждый проверяет итог:
  текст в ленте, статус «прочитано», «печатает», положение поля над клавиатурой, цитату в
  ответе, буфер обмена, «изменено» у того же пузыря, исчезновение, реакции, счётчик поиска,
  яркость обоев по пикселям после смены темы, порядок после быстрой серии отправок.
- **Perf** (`Tests/ChatLabPerfTests`, Release): запуск, прокрутка истории
  (`XCTOSSignpostMetric.scroll*`), CPU/память, клавиатура, меню, просмотрщик, серия отправок,
  входящие при прокрутке вверх (позиция не сдвигается). Монитор кадров приложения (CADisplayLink,
  элемент `perf.summary`) отдаёт fps, рывки, худший кадр; `scripts/perf_check.py` сверяет их
  с `Tests/perf-baseline.json`. Интервалы взаимодействий пишутся os_signpost
  (`kz.studenthub.chatlab`, `PointsOfInterest`) — их видно в Instruments.

## Известные ограничения и отличия от Telegram

- Ничего не проверено в работе: анимации, жесты и замеры кадров ещё предстоит посмотреть на
  iPhone. Первый прогон `scripts/test.sh` на Mac почти наверняка покажет падения UI-тестов
  из-за таймингов и запросов.
- Пружины Telegram (`CASpringAnimation` m/k/c) приближены к `UIView`-пружинам с той же
  длительностью. Отрисовка не асинхронная, как в AsyncDisplayKit: раскладка считается заранее,
  а текст рисуется на главном потоке в `draw(_:)`.
- Нет анимированных эмодзи и стикеров, «пыли» при удалении, переводов, звонков, секретных чатов.
- Меню и панели на материалах размытия, а не на `UIGlassEffect`, кроме кнопки «вниз».
- Переход в профиль системный (свайп назад работает), поверх летит аватар; кривая системная.
- Кружок записывается квадратным файлом и круглый только при показе. В закреплённой записи
  кружка нет предпросмотра.
- Встряхивание для Debug Menu не сделано (нужен подкласс окна): вместо него долгое нажатие
  тремя пальцами.
- Монитор кадров видит только главный поток; рывки рендер-сервера — в Instruments → Animation Hitches.
- Медиа генерируются при первом запуске (несколько секунд): до готовности на месте медиа
  крутится индикатор.
