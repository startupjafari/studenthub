# Карта кампуса — инструкция для администратора вуза

Для кого: администратор и модератор вуза, которые рисуют и публикуют карту. Как устроено внутри —
`docs/CAMPUS_BUILDER.md`; права и API — `docs/PROJECT.md` §3.13.

Студенты, преподаватели и охрана видят карту в меню «Карта кампуса»: поиск аудитории, этажи, 3D
и маршрут «откуда — куда». Видят **только опубликованную** версию — черновики им не показываются.

## 1. Кампус и корпуса

1. «Здания → Карта кампуса» (у модератора — пункт «Карта кампуса») → «Создать кампус».
2. В кампусе — «Добавить корпус»: форма (прямоугольник, Г, П, Т), размеры в метрах, число
   этажей, высота этажа, положение на территории. Каждый этаж сразу получает наружные стены по
   контуру корпуса.
3. «Добавить этаж» — пустой по контуру или **копия** существующего: номера помещений
   пересчитываются («3» → «4» превратит «А305» в «А405»), связь с аудиториями вуза у копии
   сбрасывается — её нужно задать заново.

## 2. Редактор этажа

«Редактировать» у этажа открывает редактор на весь экран. Он сохраняет сам: статус в шапке
(«Сохранено», «Есть изменения», «Нет сети — сохраним позже»).

| Клавиша | Инструмент | Как работает |
|---|---|---|
| V | Выделение | Клик — выбрать; узел, дверь, подпись — перетащить; стрелки — сдвиг на 10 мм (Shift — 100 мм) |
| W | Стена | Клик — начало, клики — следующие точки; двойной клик или клик в ту же точку — конец |
| R | Комната | Протянуть прямоугольник — четыре стены и помещение сразу |
| D / N | Дверь / окно | Навести на стену и кликнуть |
| S / E | Лестница / лифт | Протянуть прямоугольник |
| T | Надпись | Клик |
| M | Линейка | Протянуть |
| H или пробел | Рука | Двигать план |

- **Привязки:** к существующей точке, к стене, по горизонтали и вертикали, к сетке. Shift — шаг
  15°, Alt — без привязки.
- **Пересечения:** новая стена сама режет те, что пересекает, — отдельно соединять не нужно.
- **Помещение** — замкнутая область. Двойной клик по пустой области или «Сделать помещением» в
  свойствах. В свойствах — номер, название, назначение, вместимость, кто видит.
- **Учебное помещение** (аудитория, лекционная, лаборатория, компьютерный класс, спортзал) должно
  быть связано с аудиторией вуза — по ней работает расписание. Выберите её в поле «Аудитория вуза»
  или нажмите «Создать помещение вуза». Без связи карту не опубликовать.
- **Видимость:** «Все», «Сотрудники» (студенты не видят), «Только редакторы» (не публикуется).
- **Лестницы и лифты** разных этажей связывает одинаковая «Группа этажей» в свойствах — по ней
  маршрут переходит с этажа на этаж. Лифт отметьте «Без ступеней», иначе маршрут для коляски не
  построится.
- **Двери:** «Только сотрудники» — студенту маршрут через неё не проложится; «Закрыта» — никому.
- **Шаблоны → «Коридор с комнатами»** — коридор и комнаты по обе стороны по контуру этажа.
- **2D / 3D** — объёмный вид этажа; клик по полу выбирает помещение.
- Отмена — Ctrl+Z, повтор — Ctrl+Shift+Z.

### Проверка

Вкладка «Проверка» показывает ошибки (красные — мешают публикации) и предупреждения. Клик по
строке подводит план к месту. Ниже — «Проверка маршрутов»: какие помещения недостижимы от входа,
лестницы или лифта, и пробный маршрут между двумя помещениями.

### Двое правят одновременно

Этаж в один момент правит один человек: второй видит «Этаж сейчас правит другой редактор» и может
«Забрать правку». Если правки всё же разошлись (две вкладки), появится выбор: «Загрузить
актуальный» или «Перезаписать моим». Несохранённое при закрытой вкладке редактор предложит
восстановить при следующем открытии.

## 3. Территория

Кнопка «Территория» на экране кампуса. Граница, газоны, парковки, спортплощадки и зоны отдыха —
кликами по углам, Enter или двойной клик замыкает. Дорожки и дороги — по точкам. Деревья, ворота,
надписи — одним кликом. Корпуса перетаскиваются мышью (или координатами в свойствах).

**Дорожки важны для маршрутов:** путь между корпусами идёт по ним от входа к входу; ворота
появляются на карте как точка «Откуда» для посетителей.

## 4. Публикация

«Опубликовать» на экране кампуса. Все этажи проверяются ещё раз; если что-то мешает — список с
переходом в редактор нужного этажа. После публикации новая версия сразу видна всем.

- «Версии карты» — история публикаций. «Сделать текущей» — откат того, что видят пользователи
  (черновики не меняются). «В черновик» — вернуть черновики этажей к версии (прежние уходят в
  снимки).
- Публиковать можно не чаще двух раз за 30 секунд.

## 5. Частые вопросы

| Вопрос | Ответ |
|---|---|
| Студент не находит аудиторию | Она не опубликована, скрыта («Только редакторы» / «Сотрудники») или без номера |
| «Без лестниц сюда не пройти» | На пути нет лифта или пандуса с «Без ступеней», или у лифта разные группы на этажах |
| «Этажи не соединены» | У лестницы на соседнем этаже другая «Группа этажей» |
| «У помещения нет двери» | Поставьте дверь на его стену |
| «Показать на карте» в расписании ведёт на заглушку | Помещение вуза не связано ни с одним помещением карты |
