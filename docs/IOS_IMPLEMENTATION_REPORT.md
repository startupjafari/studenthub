# StudentHub iOS — отчёт о доработке

Ветка: `feat/ios-native-parity`. Она отведена от `feat/ios-chats-redesign`: в той ветке лежит
ещё не влитая переработка главной и чатов, на которой построена эта работа.
Дата: 2026-11-08.

Статусы по каждой функции веба — в `docs/IOS_FEATURE_PARITY.md`. Здесь — что сделано,
чем проверено и что осталось.

## 1. Что найдено в вебе

Карта функций собрана по исходникам `apps/web` (меню `widgets/app-shell/model/nav.ts`,
маршруты `app/`, API-файлы FSD) и контроллерам `apps/api` для трёх ролей приложения:
STUDENT, STAROSTA и TEACHER. По областям:

- **Соцсеть.** Лента, посты, комментарии, реакции, репосты, закладки, истории с опросами,
  ссылками, упоминаниями и актуальным, статьи, опросы, друзья, уведомления.
- **Учёба.** Расписание, календарь, «мои задачи» (производный список), дисциплины,
  задания с файлами, оценки, посещаемость, отметка по QR, экзамены, учебный план.
  Для преподавателя ещё журнал, проверка работ, материалы и группы.
- **Сервисы.** Деканат, консультации, заявки, документы и запросы документов, портфолио,
  библиотека, события, карта кампуса (2D и 3D), студенческий билет, карьера.
  Для старосты ещё приглашения и сбор документов группы.
- **Аккаунт.** Профиль и его правка, настройки: личное, безопасность, уведомления,
  внешний вид, приватность, поддержка, удаление аккаунта.

Чего нет в API и что поэтому заблокировано, — в разделе 7.

## 3. Изменённые модули

- `Core/Network`:
  - `Error.userMessage` — одна точка для текста ошибки вместо 27 копий одной и той же
    развилки;
  - `APIClient.data(_:)` — ответ без конверта, для выгрузки данных;
  - `JSONCoding.isoString`.
- `Core/Observability` — хлебная крошка `unexpectedResponse` со статусом и типом ошибки.
  Тело ответа в неё не попадает.
- Новые слои API:
  - `Core/Account/AccountAPI.swift`;
  - `Core/Feed/ProfileContentAPI.swift`;
  - `Core/Services/UniversityServicesAPI.swift`;
  - `Core/Study/CoursesAPI.swift`;
  - `Core/Campus/CampusAPI.swift` — вместе с геометрией плана.
- `Core/Feed/FeedAPI.swift`:
  - `FeedScope` — срез ленты: автор или сохранённое;
  - `UserProfileDTO` — поля `PROFILE_SELECT`, все необязательные.
- `Core/Navigation`:
  - `AppTab.more` переименован в `AppTab.services`;
  - новые разделы `consultations`, `deanery`, `portfolio`, `campusMap`;
  - маршрут `campusRoom`;
  - диплинки на эти разделы.
- `Core/Storage` — миграция `v6.pairRefs`: в кеше расписания появились `roomId` и
  `teacherId` пары. Миграция только добавляет колонки. Старые строки заполнятся при
  следующей синхронизации.
- `Resources/Localizable.xcstrings`:
  - новые строки добавлены на русском;
  - удалены осиротевшие ключи, которые `LocalizationTests` уже считал ошибкой:
    `chats.attachPhoto` и `home.feed`.

## 4. Навигация

Пять вкладок, у каждой свой `NavigationStack`. Путь хранится в `AppRouter`, поэтому
переход между вкладками ничего не теряет.

1. **Главная.** Истории, ближайшая пара, «Что нового?», лента. В панели — StudentHub,
   поиск, уведомления.
2. **Расписание.** Режимы «День» и «Неделя». Из пары — карточка занятия, оттуда — карта
   кампуса и профиль преподавателя.
3. **Чаты.** Без изменений в этой ветке.
4. **Учёба.** Сводка, сроки, разделы: дисциплины, оценки, посещаемость, задания,
   материалы, события.
5. **Сервисы.** Группы разделов:
   - Университет: деканат, консультации, карта кампуса; у преподавателя ещё дисциплины
     и группы.
   - Документы и заявки.
   - Личное развитие: портфолио.
   - Сообщество: события, одногруппники.
   - Аккаунт.

Профиль открывается аватаром слева в верхней панели корневого экрана любой вкладки. Из
профиля — сохранённое и настройки. Выход и вход по QR переехали из «Ещё» в настройки.

## 6. Сборка и тесты

**Сборка.** Каждый шаг собирался из WSL. Команда: `xtool dev build` — Swift 6.4.2 и
darwin SDK с API iOS 26. Последняя сборка — код выхода 0, `Build complete`. Новых
предупреждений нет. Остались прежние:

- `AppDelegate.swift` — `Sendable`, лишний `await`;
- `QRScannerView.swift:77` — захват `self`.

Что из этого следует:

- **Проверены:** компиляция кода приложения под iOS (arm64) и совместимость
  использованных API с SDK.
- **Не проверено:** сборка Xcode. `project.yml` содержит Sentry, а манифест xtool
  (`Package.swift`) — нет.

**Тесты.** Не запускались. Целевая платформа тестов — iOS, симулятора в этой среде нет.
Добавлен `Tests/StudentHubTests/ParityTests.swift`:

- сводка успеваемости по правилу веба;
- геометрия плана этажа;
- тело PATCH профиля по ролям;
- покрытие каталога сервисов;
- срез ленты;
- диплинки сервисов.

Тестовая цель есть только в `project.yml`, поэтому в этой среде файл даже не
компилировался. Из прежних тестов поправлен `NavigationTests`: вкладка `.services`, у
студента появился деканат.

**Строки.** Каталог синхронизирован скриптом по тем же правилам разбора, что в
`LocalizationTests`. Сам тест не запускался.

UI-тестов (XCUITest) нет: тестовой UI-цели в `project.yml` нет, а заводить её без
возможности прогнать нельзя. На ключевых контролах проставлены `accessibilityIdentifier`:
`toolbar.profile`, `services.*`, `settings.*`, `profile.tab.*`, `schedule.mode`,
`study.subjects`, `state.*`.

Ручной проверки UI не было: ни светлой и тёмной темы, ни крупного шрифта, ни малых
экранов, ни клавиатуры.

**Как собрать и проверить на Mac:**

```sh
cd apps/ios
xcodegen generate
xcodebuild -project StudentHub.xcodeproj -scheme StudentHub \
  -destination 'platform=iOS Simulator,name=iPhone 16' test
```

На телефон без Mac — `./scripts/device.sh` (см. `apps/ios/README.md`).

## 7. Заблокировано со стороны API

| Что | Почему |
|---|---|
| Список сессий и завершение одной сессии | Маршрута нет ни в API, ни в вебе. «Выйти везде» — это смена пароля, экран об этом говорит. |
| Тема на сервере | Поля нет. Тема хранится на устройстве, как и в вебе. |
| «Мои задачи» как сущность | Модели нет. Веб строит список из заявок, событий и заданий. Такой производный список на iOS ещё не сделан. |
| Календарь за диапазон дат | Запроса за период нет. Веб собирает календарь из нескольких источников. |
| Тип занятия (лекция или практика) | У пары нет такого поля. |
| Отдельный «статус» профиля | Поля нет. Используется `headline` — строка под именем. |
| Правка комментария к посту | Маршрута нет. |

## 8. Известные ограничения и отличия от веба

- **Казахский перевод.** У 554 из 861 строк нет `kk`. Сюда входят прежние строки чатов
  и все новые. Отладочная сборка подставляет русский (`device_bundle.py`). Перевод —
  отдельная задача, как в плане (21.A5).
- **Карта кампуса.**
  - Нет маршрута между помещениями: граф приходит, но поиск пути из
    `campus-core/nav/route.ts` не перенесён.
  - Нет 3D-вида.
  - Контур помещения собирается из его стен по `edges`. Если стены не сцепились, вместо
    заливки выделяется только подпись.
- **Связь пары с дисциплиной.** Пара хранит дисциплину строкой, без id, поэтому
  дисциплина и задания к паре подбираются по совпадению названия.
- **Расписание.** Нет месячного вида. Нет правки своих пар и разовых изменений у
  преподавателя.
- **Учёба.** Не сделаны:
  - файлы к сдаче задания и скачивание файлов материалов;
  - экзамены и учебный план;
  - отметка по QR;
  - журнал и проверка работ у преподавателя.
- **Лента и истории.**
  - Пост: нет выбора аудитории, фильтров ленты, черновиков, отложенных постов,
    отправки поста в чат.
  - Статьи и альбомы нельзя открыть и создать.
  - Истории: нет актуального, нет списка зрителей, в редакторе нельзя добавить
    интерактивные элементы.
  - Предзагрузки соседних историй нет.
- **Профиль.** Нет списка друзей, студенческого билета, смены логина.
- **Сервисы.**
  - Документы: нет загрузки и запросов документов.
  - Заявки: нет вложений.
  - События: нельзя создать событие и написать комментарий.
  - Нет карьеры и инструментов старосты (приглашения, сбор документов).
  - Сервер может отключить раздел целиком (`platform/state`); приложение это не
    учитывает.
- **Восстановление после перезапуска.** Путь в стеке вкладок и позиция прокрутки не
  сохраняются между запусками.
- **Язык писем и пушей.** Он задаётся полем `locale` профиля, а экран языка ведёт
  только в настройки iOS. Чтобы письма приходили на новом языке, нужен отдельный выбор
  с `PATCH /users/me {locale}`.
